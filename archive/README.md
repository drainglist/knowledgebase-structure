# Архив прежней системы

`legacy/` — снимок системы тем, утверждений, проверок и старого дэшборда
перед переходом к хранению статей для RAG. Снимок включает последнюю
оптимизацию SQL-поиска из Git:
`794d575d4ab3defbdab469638c6981dde373a5d4`.

Сохранены исходники, тесты, ресурсы интерфейса, прежние `pom.xml`,
`compose.yaml` и README. Это отдельный архив вне активного `src/`:
он не компилируется, не сканируется Spring и не включается в рабочий jar.
Полезные части можно переносить в новую систему выборочно.

## Копия прежней базы

Локальная резервная копия находится в
`backups/legacy-2026-10-26/database.dump` в корне проекта.
Копия БД сделана до обновления архивного SQL-поиска, на версии приложения
`8e2842dc7a473177c6eb6a3448ba84bb3e2bf6d8`.
Рядом находятся результат проверки `verification.json` и прежний `.env`
под именем `legacy.env`, если он существовал при архивировании.
Каталог `backups/` исключён из Git: эти файлы нужно сохранять отдельно,
если требуется перенести архив на другой компьютер.

Копия создана через `pg_dump` в custom-формате. Она успешно восстановлена
в отдельную временную PostgreSQL; число строк во всех девяти таблицах
совпало с оригиналом. Контрольные суммы файла в контейнере и локальной
копии также совпали. Только после этой проверки старая база была удалена
и создана заново без прежних таблиц.

## Восстановление для изучения

Используйте отдельную базу, не рабочую базу новой системы. Из корня проекта,
при запущенной PostgreSQL и стандартном локальном пользователе:

```powershell
docker compose cp backups/legacy-2026-10-26/database.dump postgres:/tmp/legacy.dump
docker compose exec -T postgres createdb -U water_knowledge legacy_restore
docker compose exec -T postgres pg_restore -U water_knowledge --dbname=legacy_restore --exit-on-error --no-owner --no-privileges /tmp/legacy.dump
```

При необходимости запустить архивное приложение задайте ему отдельный
`DB_URL`, указывающий на `legacy_restore`, и отдельный `PORT`. Не запускайте
архив против базы новой системы: старый Hibernate создаст в ней прежние
таблицы. Сам архив не подключён к основной сборке.
